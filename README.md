# ImmortalSerg Home Assistant Apps

Общий каталог: https://github.com/immortalserg/ha-apps

## Приложения

- **FinWorkspace** — приложение для управления финансами (синхронизируется из [FinWorkspace-HA](https://github.com/immortalserg/FinWorkspace-HA)).
- **Paperless Auto Metadata** — обработка OCR с пользовательскими правилами и необязательным переводом.

## Paperless Auto Metadata v1.3.0

Добавь каталог в Home Assistant → Settings → Apps → App Store → ⋮ → Repositories, установи приложение и открой **Open Web UI**.

**В новой установке нет ни одного предустановленного регулярного выражения.** Адрес Paperless и API-токен тоже не предзаполнены. Правила можно добавлять, удалять и назначать любым полям, корреспонденту и заголовку документа. Веб-интерфейс загружает имена пользовательских полей из API Paperless.

### Перевод

Перевод не требует регулярных выражений и работает независимо от них.

1. Установи и запусти отдельный сервер [LibreTranslate](https://github.com/LibreTranslate/LibreTranslate) либо укажи доступный адрес совместимого API. LibreTranslate **не входит** в контейнер приложения.
2. В **Open Web UI → Перевод OCR** включи перевод и введи URL сервера (например, `http://192.168.1.20:5000`).
3. Выбери **пользовательское текстовое поле Paperless**, куда сохранять перевод. Поле должно существовать заранее; желательно тип **Long text** (или совместимое строковое поле).
4. Укажи язык оригинала (`auto` по умолчанию) и язык перевода (`ru` по умолчанию). При необходимости укажи API-ключ и лимит символов.
5. Оставь включённым **Тестовый режим**, проверь документ и журналы, затем отключи тестовый режим и сохрани настройки.

В перевод отправляется OCR-текст документа (до установленного ограничения). Перевод сохраняется в выбранном пользовательском поле через API Paperless, существующие другие поля сохраняются.

**Приватность:** при использовании стороннего сервера LibreTranslate содержимое документа отправляется этому серверу. Для конфиденциальных документов рекомендуется локальный LibreTranslate.

### Обновление с v1.2.x

- Удалён прежний встроенный набор из пяти банковских правил.
- Старый неизменённый набор банковских правил автоматически убирается из сохранённых настроек при запуске новой версии.
- Самостоятельно созданные правила пользователя сохраняются.
- Для полного удаления всех своих правил используй веб-интерфейс: удали карточки и сохрани.
- Адреса и токены уже установленного приложения сохраняются; пустые значения по умолчанию относятся к **новым установкам**.
- Перевод по умолчанию **выключен**. Для работы нужен сервер LibreTranslate.
- Настройки находятся в `/data/settings.json`, токены не показываются повторно.
- Тестовый режим по умолчанию включён, пока пользователь сам его не отключит.

### Важно о FinWorkspace

Не удаляй установленный FinWorkspace из прежнего каталога без резервной копии базы и плана миграции: Home Assistant может считать его другим приложением.

## LibreTranslate

[LibreTranslate](libretranslate/README.md) — локальный сервер перевода для Home Assistant и Paperless Auto Metadata. После установки API доступен на `http://HOME_ASSISTANT_IP:5000` (только в доверенной сети).
